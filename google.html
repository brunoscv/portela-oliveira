Instruções para integração dos Comentários do Google

Olá! Para que possamos exibir as avaliações do seu escritório/empresa automaticamente no site e mantê-las sempre atualizadas, o Google exige uma "chave de acesso" (API Key).

Abaixo está o passo a passo para gerar essa chave. É um processo que exige uma conta do Google (Gmail).

Passo 1: Acessar o Google Cloud

  1. Acesse o Google Cloud Console.
  2. Faça login com sua conta do Google.
  3. Se for seu primeiro acesso, aceite os termos de serviço.

Passo 2: Criar um Projeto

  1. No topo da página, clique na lista de projetos (geralmente diz "Selecione um projeto" ou "My First Project").
  2. Clique em "Novo Projeto" no canto superior direito da janela que abriu.
  3. Dê um nome ao projeto (Ex: Site-Avaliacoes) e clique em Criar.

Passo 3: Ativar a API "Places API"

  1. No menu lateral esquerdo, vá em APIs e serviços > Biblioteca.
  2. Na barra de pesquisa, digite: Places API.
  3. Selecione Places API (New) ou apenas Places API.
  4. Clique no botão azul Ativar.
Nota: Se o Google pedir para ativar o faturamento (Billing), você precisará adicionar um cartão de crédito. O Google oferece US$ 200,00 de crédito gratuito todo mês, o que é mais que suficiente para exibir avaliações no site sem custo, mas o cadastro do cartão é obrigatório para verificar a conta.

Passo 4: Criar a Chave de API (Credenciais)

  1. Após ativar, vá no menu lateral esquerdo em APIs e serviços > Credenciais.
  2. No topo, clique em + CRIAR CREDENCIAIS e escolha Chave de API.
  3. Uma janela mostrará sua chave (um código longo começando com AIza...).
  4. Copie esse código e me envie.

O que eu preciso que você me envie:

  1. A Chave de API gerada acima.
  2. O Nome exato da sua empresa como aparece no Google Maps.
